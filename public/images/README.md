# Hero + shared images

- `hero.jpg` — home page hero background (landscape photograph). Loaded
  via CSS `background-image` inside the Ken Burns container in
  `src/app/page.tsx`. Recommended: ~2400 px on the long side, sRGB,
  ~80 % JPEG quality. If the file is missing, the underlying
  wood-toned gradient still shows so the layout never breaks.

Project photos live in `./projects/` — see the README there.
