# Project photos

Real photos for entries in `src/data/projects.ts`. When a project has an
`image` field (path relative to `/public`), the card in the featured
mosaic on `/` and the full mosaic on `/prosjekter` renders the photo
instead of the gradient. If the file is missing, the gradient stays
visible as a fallback.

Filenames used in code:

- `baderom.jpg` — the "Baderom i tre og stein" project.

Prefer JPEG at ~1600 px on the long side, sRGB, ~75–85 % quality.
