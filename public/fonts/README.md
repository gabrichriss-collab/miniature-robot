# Fonts

Drop your licensed Penumbra Std webfonts here so the CSS `@font-face`
declarations in `src/app/globals.css` pick them up automatically:

- `PenumbraStd-Regular.woff2`
- `PenumbraStd-SemiBold.woff2`

Until they are in place, the site falls back to **Cormorant Garamond**
(loaded from Google Fonts in `layout.tsx`) so the overall serif tone
still reads as intended.

**Sorts Mill Goudy** (used for headlines / h1) is served from Google
Fonts and requires no action.
